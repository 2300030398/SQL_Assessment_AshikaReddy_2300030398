# SQL Assessment – Database Practice 🗄️

## About the Project

This project is a collection of SQL queries and database exercises that I worked on to improve my SQL skills. I practiced creating databases and tables, inserting data, retrieving information, filtering records, and analyzing data using different SQL operations.

While working on this assessment, I also explored how tables are connected and how SQL can be used to retrieve meaningful information from multiple tables.

## What I Practiced

- Creating databases and tables
- Inserting records into tables
- Retrieving data using `SELECT`
- Filtering records using `WHERE`
- Sorting data using `ORDER BY`
- Using `LIKE`, `BETWEEN`, and `IN`
- Applying constraints such as `PRIMARY KEY`, `UNIQUE`, and `FOREIGN KEY`
- Adding columns using `ALTER TABLE`
- Using aggregate functions like `COUNT`, `SUM`, `AVG`, `MIN`, and `MAX`
- Grouping data using `GROUP BY` and filtering groups using `HAVING`
- Writing subqueries and correlated subqueries
- Performing `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `CROSS JOIN`, and self joins
- Combining query results using `UNION`

## Topics Covered

### 1. Basic SQL Operations
Created databases and tables, inserted records, viewed table structures, and retrieved data using basic SQL commands.

### 2. Constraints
Practiced using primary keys, unique constraints, foreign keys, `NOT NULL`, and default values to maintain data consistency.

### 3. Filtering and Sorting
Used conditions to filter records based on names, salaries, ages, departments, and joining dates.

### 4. Aggregate Functions
Used aggregate functions to calculate employee counts, total salary, average salary, minimum salary, and maximum salary.

### 5. Grouping and Subqueries
Grouped employee records department-wise and used subqueries to find employees earning the highest salary, below-average salary, and above their department's average salary.

### 6. Joins
Practiced joining customer, employee, student, category, product, and order-related tables to retrieve information from multiple tables.

### 7. Order Management Database
Created a separate `orders` database containing categories, products, and order details. Used joins to retrieve product and category information and calculated category-wise sales.
